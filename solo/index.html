🚀 Getting Started with Solo Play

  1. Read the Rules: Start with the core game rules above
  2. Create Characters: Make 3 characters using the rules
  3. Choose an Adventure: Pick from the solo adventures or ask your AI GM to create one
  4. Use the Oracle: Roll 2d6 for yes/no questions (8+ = Yes)
  5. Consult Tables: Use random tables when you need inspiration
