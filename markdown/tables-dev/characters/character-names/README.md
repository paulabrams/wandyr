# Dragon Isles Random Names

**Name lists for all ancestries and regions in the Dragon Isles setting**


## Usage

Each file contains:

- **d20 Rollable Lists** - Numbered 1-20 for easy random generation
- **Names** - Male and female names where applicable
- **Surnames** - Family names and titles
- **Epithets** - Titles and honorifics for some races
- **Homelands** - Regions and territories
- **Naming Notes** - Cultural context and naming conventions
- **Cultural Notes** - Additional background information

These name lists can be used for:

- Character creation
- NPC generation
- Worldbuilding
- Random name generation

All names are extracted from the Dragon Isles setting and maintain the cultural authenticity of each race. Simply roll 1d20 and consult the appropriate list for instant name generation.
