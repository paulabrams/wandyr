## Observations

1. This character's spellbook is from version 0.1 (January 2025) and contains 12 spells from 1st-3rd level. New spellbooks normally just have a single 1st level spell each, but this is grandfathered in for this character.
2. The player asked if they could buy nicer strings/etc to improve their harp; they paid 100 gp for +1. This is not mentioned in the rules directly, but clearly seems implied with examples such as "masterwork" sword +1.
3. The player asked if their harp could be considered an Arcana, so we were trying that out. In the latest rules this would have required spending 1000 gp to make a "custom" Arcana item. The player has already invested several spells into the harp. We could either grandfather this in or say the 1000 gp are needed before the item can grant Arcana Hearts or receive more spells. It's worth noting that improving the music instrument strings doesn't improve the Arcana aspect of the harp. TODO - ask how much was actually spent
4. The player asked if they could buy better jewels/etc to improve the scabbard of their +1 dagger to become an Arcana, so we were trying that out. I think they might have spent 100 gp on buying a separate "plus" for the Arcana (which might have had a benefit in various interim rules proposals, but has no benefit now, and so should be removed). In the latest rules this requires spending 1000 gp to make a "custom" Arcana item. TODO - ask how much was actually spent
5. The player asked if their earring is an Arcana. The rules have always stated that Arcana are magic items usable only by magic-users. So the earring has never been an Arcana per the rules, but could become one if character wants to spend 1000 gp to create a custom Arcana.
6. The latest rules say this character is a "Magic-User 3rd level" for the purposes of Arcana. Depending on the above decisions about grandfathering in the harp and dagger, the character will either have zero or two Arcana items, and therefore zero or two Arcana Hearts
