# Wåndyr Update Briefing: v0.8 → v1.1

## Major System Changes

### 1. **Hearts System - No Change**

- **OLD**: Roll **2d6 Hearts** at Muster
- **NEW**: Roll **2d6 Hearts** at Muster (same)
- *Note*: Party Level bonus from home base removed in v1.1

### 2. **Party Level → Alignment System**

- **OLD**: Shared Party Level that affected Hearts and Oracle difficulty
- **NEW**: **Alignment** replaces Party Level as the core progression mechanic
  - Alignment = (relevant Advancements ÷ 3, rounded down)
  - Used for magic schools, fighting styles, factions, otherworldly beings
  - Determines maximum spell level, Knack usage, etc.
- *Why*: More flexible, character-specific progression

### 3. **Experience Points - Flat Rate**

- **OLD**:
  - Variable costs: 3rd Trait = 3 XP, 5th Skill = 5 XP
  - Names cost 1 XP (must be earned first)
- **NEW**: **Everything costs 3 XP** (Traits, Skills, Bynames, Spells, Arcana, Relics, Knacks, Songs, Recipes)
- *Why*: Simpler, easier to remember, encourages diverse advancement

### 4. **Morale System - Expanded**

- **OLD**:
  - Comforts: +1 or +2 Hearts during Muster (10gp or 100gp)
  - Music: Performance once per Muster per instrument Skill and song Name
  - Performance takes 10+ minutes, can restore 1 Heart per audience member (up to Hearts at Muster)
  - Audience size = Name level + Skill level + instrument slots
- **NEW**: Comprehensive morale system with four pillars:
  - **Leadership**: Party Leader gains extra Hearts = Alignment Level, can absorb damage for companions
  - **Hospitality**: Share provisions (1 Heart/hour), Comforts (+1 or +2 Hearts), Host role
  - **Music**: Performance (1 Heart/hour) + Bard role (Action to restore 1 Heart)
  - **Animal Companions**: NPC Action to restore 1 Heart per Muster
- *Why*: Emphasizes the journey and companionship themes, more structured

### 5. **Magic System - Spell Levels**

- **OLD**:
  - Pay 1 Heart for normal 1st level spell
  - Magic Component reduces cost by 1 Heart per item slot
  - Can boost beyond Party Level (risky)
- **NEW**: **Spell Level system**
  - Guide sets Spell Level based on what you're trying to do
  - Pay that Level in Hearts (use Arcana Hearts first)
  - Maximum Level = your Alignment with that magic school
  - Roll Oracle for control (not success/failure)
  - No Magic Components mentioned
- **Arcana Hearts**: New! Gain 1 Arcana Heart per Arcana item (up to Alignment), used for casting and against hostile magic
- *Why*: More structured, clearer limits, Arcana more valuable

### 6. **New Magic School: Canting**

- **NEW**: 7th magic school - Thieves' Cant magic
- 36 spells focused on deception, manipulation, thievery
- Examples: *Mark the Gull*, *Budge*, *Darkmans Cloak*, *Prince of Thieves*
- *Why*: Expands magic options for roguish characters

### 7. **Combat Timing**

- **OLD**: Everything measured in "Turns" (10 minutes)
- **NEW**: **Rounds** (10 seconds) for combat, **Turns** (10 minutes) for exploration
- Turn Clock paused during combat
- *Why*: Better distinction between fast-paced action and exploration

### 8. **Death System - Redesigned**

- **OLD**: 0 Hearts = injured, below 0 = dying (dies when Turn Clock clears)
- **NEW**: **Offscreen vs Onscreen death**
  - **Offscreen**: Cut away immediately, uncertain fate, can return via Invocation (unless Double Spicy)
  - **Onscreen**: One final heroic action (requires Sweet), then Offscreen
- *Why*: More narrative control, less mechanical death

### 9. **Insight System - Updated**

- **OLD**: 6 options: CONCEPT, SKILL, ITEM, NAME, ASSIST, EFFORT
- **NEW**: 6 options with changes:
  - CONCEPT → **TRAIT** (your approach matches a Trait)
  - NAME → **BYNAME** (titles, epithets, named items)
  - ASSIST → **FEAT** (you've done this before)
  - Still has: SKILL, ITEM, EFFORT
- *Why*: Better reflects new advancement system, clearer terminology

### 10. **Attempting the Extraordinary**

- **NEW**: System for heroic feats, spells, invocations
  - Guide assigns Level based on what you're trying to do
  - Pay Level in Hearts
  - Maximum Level = relevant Alignment
  - Roll Oracle for success
- *Why*: Unified system for extraordinary actions

### 11. **Invocations - Streamlined**

- **OLD**:
  - Lose d6 Hearts and XP
  - Roll Oracle if being notices (Sweet = likes, Spicy = dislikes)
  - Being spends XP to bring character into alignment (ask Oracle how)
- **NEW**:
  - Lose d6 Hearts first
  - Roll Oracle for response (Sweet = likes, Spicy = dislikes)
  - Guide rolls on secret Trait table for the being
  - If you already have the Trait = harmony (no cost)
  - Otherwise, being spends 3 XP on that Trait
- *Why*: Clearer process, more predictable costs, specific Trait assignment

### 12. **Relics - Enhanced**

- **OLD**:
  - Can have Names, speaking Name with correct alignment activates sacred power
  - Once per Muster per Name (as with other Named items)
  - Being might also speak a Name
  - Names often oral tradition, need Lore to discover
- **NEW**:
  - "Ark" mechanic: +1 Alignment for similar Invocations
  - "Saint" mechanic: If you muster with a Relic of a being you're Aligned to, you're a "saint"
  - Can *bless* companions at Muster (1 extra Heart each)
  - Blessing tied to rumors the being likes
- *Why*: Makes Relics more meaningful, encourages party cooperation

### 13. **Rumors & Locations Tables**

- **NEW**: Full d66 tables for rumors and locations
- Rumor updates: Guide combines results as rumors evolve
- Location updates: Can combine results when visiting
- *Why*: More tools for emergent play

### 14. **Equipment Pricing - Detailed**

- **NEW**: Clear pricing guide
  - Common: 1gp/slot
  - Armaments: 5gp/slot
  - Niche: 10gp/slot
  - Masterwork: +100gp (+1), +1,000gp (+2)
  - Elevated: +10gp (good), +100gp (rich), +1,000gp (noble)
- *Why*: Easier for Guide to price items

### 15. **Baggage - Clarified**

- **NEW**: More specific rules
  - Dropping Baggage = 1 Round (10 sec)
  - Accessing items = 1 Turn (10 min)
  - Also counts if hands occupied with non-item-slot items
- *Why*: Clearer trade-offs

### 16. **Double Sweet/Spicy - Knacks**

- **NEW**: Double Sweet can lead to learning a **Knack** (3 XP)
  - Signature move learned through Double Sweet
  - Future use limited by Alignment
  - May need extraordinary circumstances to repeat
- *Why*: Rewards exceptional moments

### 17. **Combat - "At the Same Time"**

- **NEW**: If targeted, you can act simultaneously
  - "Right of way" determines order
  - Weapon attacks > everything else
  - Melee > missiles
  - Reach matters at distance, smaller weapon in close quarters
- *Why*: More dynamic combat

### 18. **Monsters - Alignment-Based**

- **OLD**: Compared to Party Level
- **NEW**: Compared to **Alignment Level** (use Party Leader's when working together)
- *Why*: Consistent with new Alignment system

## Minor Changes

- **Elementalis** → **Elementale** (name change)
- **Umbrakala** → **Umbrakallo** (name change)
- Spell lists use **1.1, 1.2** format instead of **1.1.1, 1.1.2**
- **Learning Spells**:
  - OLD: Cast with Sweet, pay 1 XP, gain as Name, spell vanishes from book
  - NEW: Cast with Sweet, eligible to learn for 3 XP, can cast without book (known spell)
- **Arcana**:
  - OLD: Can use each Name once per Muster at no Hearts cost if visible
  - NEW: Grants +1 to caster level, provides Arcana Hearts, transfer known spell for 3 XP
- **Spellbooks**:
  - OLD: 1-4 item slots, one spell per slot
  - NEW: Most spellbooks have a single spell
- More detailed item slot examples
- Camp vs Home Base distinction clarified
- Equipment section expanded
- Better organization and formatting throughout

## What Stays the Same

- Core Oracle mechanics (2d6, 8+ = Yes)
- Sweet & Spicy system
- Character creation (2 Traits, 2 Skills)
- 10 Item Slots
- Magic school structure
- Spell lists (same spells, different numbering)
- Basic combat flow
- Turn Clock system

## Migration Notes

- **Existing characters**: Convert Party Level to relevant Alignments
- **Existing XP**: All advancements now cost 3 XP (may need adjustment)
  - Names that cost 1 XP now cost 3 XP
  - Traits/Skills that cost variable XP now all cost 3 XP
- **Existing spells**: Still work the same, but now use Spell Level system
- **Existing Arcana**:
  - Now grant Arcana Hearts (1 per item, up to Alignment)
  - Grant +1 to caster level when casting those spells
  - No longer "free cast once per Muster" - use Arcana Hearts instead
- **Magic Components**: No longer mentioned - may need to adapt or remove
- **Party Level**: No longer grants Hearts bonus from home base - replaced by Party Leader Alignment bonus
