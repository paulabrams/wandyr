# Relics

Relics are objects with connections to otherworldly beings. They are conduits for alignment, and have even been known to make Invocations or whisper mystical secrets. Relics are often mistaken for “cursed” magic items.

## Carrying Relics

When a character first encounters a Relic, ask the Oracle if the otherworldly being accepts them as the bearer. The character will intuitively feel whether they have been accepted or rejected. If rejected, continuing to carry the Relic will feel profoundly wrong. On Sweet or Spicy, the being might make a more direct connection, such as blessing/smiting the character or communicating with them.

## Using Relics

As with other Named Items, the character may use each Name once per Muster. However, the otherworldly being can also use the same Name (as determined by the Guide). Each Name can only be used once per Muster, regardless of who uses it.

This creates interesting dynamics. The character may find themselves unable to use a Name because the being has already used it, or compelled to use it in ways that align with the being's nature. Sometimes the being's intervention might be advantageous, such as healing when the character is down.

Since the being can use Names from the item, the character may find themselves affected unexpectedly. Depending on the outcome, a Relic might feel like a "cursed" magic item.

## Creating Relics

Creating a Relic is similar to creating a Named Item. The character must accomplish a significant deed, then purchase the Name with XP and assign it to the item. The Name must be appropriate to the being that will be associated with the Relic, and the character must have a connection to that being. Often the item must also be something the being finds appropriate and worthy.
