# Warband

## About this Project

Warband is my latest TTRPG project.

I've written three games that focus around the concept of a character sheet without numbers. Both started quite simple. Both became increasingly complicated as we tried to change the core concept that they started from.

- In Legends we tried to add on tactical combat.
- Loot was always simple, but did not have enough depth for campaigns.
- In Wandyr we tried to add on character advancement.

## Priority Queue

- summarize characters in Legends vs Wandyr
- choose the character sheet format for Warband
- decide if it would be simpler to modify Legends Wandyr than make a new game

## Characters

The full comparison of how characters work in Legends and Wåndyr is in [[Legends vs Wandyr — Character Comparison]]. Takeaway for Warband: both games already advance richly, so the work is **choosing which advancement shape to keep**, not inventing one — Wåndyr's traits/skills line and item slots as the lean base, with Legends' Asset/Secrets depth and the Theme→Approach swap layered on.

### Things I want to include

- Approaches (wandyr alignments) in place of Themes

## Game Engine

- game engine should focus on actions with a cost

### Hazards

- hazards are part of scenes that have a risk and cost
- hazards have a cost, which players can determine by asking
- hazards are always telegraphed
- hazards have a rank/degree, which is like hit points
