# Cheating Death (Final)

At 0 Hearts: Choose how the character falls:
Offscreen: The character collapses. The player brings in another character next round.
Onscreen: Describe one final heroic action. The character takes this action next round, then goes offscreen. Ask the Oracle if the action succeeds—heroic feats require Sweet. If the roll is Spicy (any die shows 1), the character is dead immediately with no uncertainty.
Offscreen deaths are uncertain. At any future Muster, the player may let the character pass on, or make an Invocation to return. The character must purchase one Trait (ask the Oracle what mark this leaves on the character). If the Invocation rolls double 1s, the character is dead with no uncertainty.

Perfect. Double Spicy (double 1s) = ~3% chance of permanent death on return. That's rare enough to not feel punishing, but present enough to create real tension when rolling the Invocation.
The escalating Trait cost also means by your 4th-5th return, you're paying 6-7 XP AND risking that 3% instant death. Natural brake on serial returners.Retry
