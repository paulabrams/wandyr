# Historical Events

Roll 2d6 for historical events that shaped the world:

**1.1** Great War - Nations fought, borders redrawn  
**1.2** Plague - Disease decimated population  
**1.3** Golden Age - Peace and prosperity flourished  
**1.4** Dark Age - Knowledge lost, civilization declined  
**1.5** Migration - Peoples moved to new lands  
**1.6** Discovery - New lands or magic found

**2.1** Empire Rise - Powerful nation conquered others  
**2.2** Empire Fall - Great civilization collapsed  
**2.3** Religious Schism - Faiths split into factions  
**2.4** Cultural Renaissance - Arts and learning flourished  
**2.5** Technological Revolution - New inventions changed society  
**2.6** Magical Awakening - Magic became more common

**3.1** Natural Catastrophe - Disaster changed landscape  
**3.2** Celestial Event - Stars or moons affected world  
**3.3** Divine Intervention - Gods directly influenced events  
**3.4** Prophecy Fulfilled - Ancient prediction came true  
**3.5** Hero's Journey - Legendary figure saved world  
**3.6** Villain's Reign - Evil tyrant ruled briefly

**4.1** Trade Route Established - Commerce connected lands  
**4.2** Great Library Built - Knowledge preserved for ages  
**4.3** Sacred Site Created - Holy place became pilgrimage destination  
**4.4** Monster Invasion - Creatures threatened civilization  
**4.5** Alliance Formed - Nations united against threat  
**4.6** Treaty Signed - Peace ended long conflict

**5.1** Artifact Discovered - Powerful magic item found  
**5.2** Ancient Ruins Found - Lost civilization uncovered  
**5.3** Portal Opened - Gateway to other world discovered  
**5.4** Dragon Awakened - Ancient creature stirred  
**5.5** Undead Rising - Dead returned to life  
**5.6** Fey Invasion - Otherworldly beings appeared

**6.1** Time Distortion - Past and future briefly merged  
**6.2** Reality Shift - Laws of nature changed  
**6.3** Memory Storm - Collective consciousness altered  
**6.4** Prophecy Written - New prediction created  
**6.5** Soul Migration - Spirits moved between worlds  
**6.6** Balance Restored - Natural order reestablished
