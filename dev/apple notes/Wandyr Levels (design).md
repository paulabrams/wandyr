# Wåndyr Levels

If we want to be compatible with D&D then we may need Levels?

## Wandyr Levels

- Characters are comprised of Traits
- There are subtypes of traits: Skill, Sigil, True Name
  - A Trait that is the name of an item is a "skill"
  - A Trait that is the name of a song, story, byname, or weapon name is a "sigil"
  - A Trait can also be a True Name
- Traits have levels
  - Traits start at level 1
  - Trait levels are used to set oracle target
  - A magic-school trait level is your caster level
- Advancement
  - Pay XP to level up a trait
  - Pay XP to gain a new trait

## Enchanting Arcana

- Enchanting an Arcana with a spell costs 500 gp per spell level
- This does NOT cost XP
